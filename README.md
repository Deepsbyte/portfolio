# Deepthi Kumar Portfolio

The personal portfolio of Deepthi Kumar, a full-stack software engineer and computer science student. It showcases selected projects, technical skills, experience, and creative work.

## Tech stack

- React 18
- Vite
- Tailwind CSS
- JavaScript

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

[View the portfolio](https://deepthi-portfolio.vercel.app/)
