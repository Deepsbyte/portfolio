## A little about me

I am a computer science student and software developer based in Bengaluru, India. I enjoy taking an idea from a blank canvas to a deployed product: shaping the data model, wiring the APIs, and making the interface feel clear and human.

My work sits across React, Django, FastAPI, databases, and the small details that make a product pleasant to use. I am especially drawn to full-stack problem solving, useful abstractions, and learning by building.

## Run it locally

```bash
npm install
npm run dev
```

For a production build and local preview:

```bash
npm run build
npm run preview
```

The site is built with React 18, Vite, Tailwind CSS, and JavaScript.
